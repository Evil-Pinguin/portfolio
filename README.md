# portfolio

Личное портфолио проектов: собирает все ваши проекты в одном месте.

## Возможности
- Категории: Сайт, Игра, Обучение, Другое (фильтр в боковой панели)
- Название большими буквами с историей версий (1.0 → 1.1 → 1.2 …); каждое изменение названия поднимает версию, из истории можно вернуться к прошлому названию
- Описание, цели и задачи (задачи можно отмечать выполненными)
- Ссылки: GitHub, сайт, проект — через кнопку «+»
- Иконка проекта (эмодзи или своя картинка) и галерея фото: квадратные миниатюры в сетке
- Предпросмотр сайта в самом конце страницы (по ссылке типа «Сайт»)
- Светлая и тёмная тема в стиле GitHub

## Деплой на Vercel
Проект — статический сайт без сборки. Конфиг лежит в `vercel.json`: корневая папка выдачи — `public/`.

1. В Vercel нажмите **Add New → Project** и выберите репозиторий `Evil-Pinguin/portfolio`.
2. Оставьте Root Directory пустым (корень репозитория), Framework Preset — **Other**.
3. Build Command и Install Command оставьте пустыми — Vercel возьмёт настройки из `vercel.json`.
4. Нажмите **Deploy**.

После этого каждый push в ветку создаёт превью-деплой, а `main` — продакшен.

## Запуск
Никаких зависимостей не нужно. Данные сохраняются в браузере (localStorage).

```bash
cd public
python3 -m http.server 3000 --bind 0.0.0.0
```

Откройте http://localhost:3000.
